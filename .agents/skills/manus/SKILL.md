# Manus (manus.im) Agent Bridge & Workflows

[Manus](https://manus.im) is an autonomous general-purpose AI agent designed to execute long-running, multi-step tasks in cloud sandbox environments. This skill outlines the integration bridge between this repository and Manus.

## Integration Modalities

### 1. Two-Way GitHub Repository Sync
Manus connects natively to GitHub to inspect, edit, and push changes to projects asynchronously:
- **Repository Link**: Connect `inovatist699/Expert-palateo` in Manus under **Settings -> Integrations -> GitHub**.
- **Autonomous Delegation**: Use Manus for long-running tasks that run independently in the cloud (e.g., crawling and curating new venue datasets, performing competitor UX audits, or running regression test suites).
- **Branching Protocol**: Configure Manus to push proposed changes to dedicated feature branches (e.g., `manus/venue-sync` or `manus/ui-enhancements`) so changes can be audited locally before merging.

### 2. MCP & API Connectors
Manus communicates with external systems using the **Model Context Protocol (MCP)** and its REST API:
- **API Documentation**: Refer to the [Manus API Documentation](https://manus-api.mintlify.app/) for programmatically triggering agent runs, passing prompts, and retrieving generated artifacts.
- **MCP Servers**: Expose local tools (e.g. database schema validators, recommendation scoring scripts in `work/`) via custom MCP servers when running Manus workflows.

### 3. Workflow Division: Antigravity vs. Manus

| Capability | Local Antigravity Agent | Cloud Manus Agent (manus.im) |
| :--- | :--- | :--- |
| **Primary Scope** | Interactive pair programming, rapid local verification, precise code editing | Autonomous, long-running, asynchronous tasks, cloud web crawling & research |
| **Execution Environment** | Local machine & local workspace files | Isolated cloud sandbox with independent browser and terminal |
| **Turnaround** | Immediate, synchronous conversation turns | Background jobs that continue even after closing your editor |

## Review & Merge Protocol for Manus Output
When pulling changes or artifacts generated by Manus into `Palateo`:
1. Run local validation: `npm run check`
2. If inline JavaScript was altered: `npm run update:csp`
3. Preview changes locally: `node work/preview-mobile-taste.cjs`
