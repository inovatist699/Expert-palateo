# App and website audit — 17 October 2026

## Fixed reproducible issues

- Missing/unsupported opening hours previously produced an invented 11:00–23:30 schedule or a type error. Unknown hours stay unverified; validated 12/24-hour and overnight ranges remain supported.
- Restaurant details previously converted review snippets into menu items with guessed prices and dietary labels. Only listed menu data is presented as menu information; other dishes are explicitly labelled taste examples from the existing dietary-filtered calibration catalogue.
- Some detail dish votes used IDs that the learner rejected. Example votes now use canonical calibration IDs and support learning/undo. Unmapped menu items do not offer ineffective learning buttons.
- Removed the unsupported Maps verification claim; the control now opens Maps.
- Passport visit history was derived from filtered recommendations. It now reflects active visit history in the selected city regardless of recommendation filters. Keyboard activation, close focus and opening a visit without a lingering overlay are covered.
- Image fallback used inline event handlers blocked by production CSP. A delegated handler now handles first failure and stops retrying after fallback failure.
- Android Back now closes Passport/deletion/sign-in overlays first and uses the details return path rather than always jumping home.

Full regression suite including new venue-details/native-navigation tests; dietary, pass/undo, saved, dish-learning, Passport and details browser flows; responsive entry/login/signup/waitlist checks; disposable local account deletion; packaged mobile web boot under CSP; browser navigation across all catalogue cities at mobile, small-screen and desktop widths; map interactions with a deterministic map-provider fixture. Existing screen text/computed-style parity and no-overflow checks pass for unaffected screens.

Read-only production checks passed for routing, public assets, CSP hash, legal pages, private-file protection, Supabase Auth health and anonymous account-data isolation. Server/mobile dependency audits reported zero vulnerabilities. AI route authentication, limits and failover passed mocked-provider tests.
